03 — FEATURED PROJECT

Password Protected Door Lock System

01

Smart IoT Door Lock

LIVE CONCEPT

A password-based smart security system developed using Arduino. The user enters a password through a keypad, and the system verifies the password for secure access control.

It supports automatic locking, motion detection and alarm functionality. ESP8266 Wi-Fi connectivity is used to send Telegram alerts for person detection, door unlocking, locking and alarm events.
